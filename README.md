# 🍕 Pizza Inn Sales Analysis Dashboard

This project analyzes **one year of pizza sales data** from Pizza Inn to gain valuable insights into customer behavior and business performance. Using **SQL**, **Excel**, and **Power BI**, we focused on calculating and visualizing key performance indicators that can help the business grow smarter.

---

## 📌 Project Objectives

To answer the question: **“How is our pizza business really performing?”**, this project focused on analyzing the following key metrics:

1. **Total Revenue**  
   > The total value of all pizza sales across the year.

2. **Average Order Value (AOV)**  
   > The average amount a customer spends per order, calculated as:  
   `Total Revenue ÷ Total Number of Orders`

3. **Total Pizzas Sold**  
   > The total quantity of pizzas sold in 2023.

4. **Total Orders**  
   > The complete number of unique orders placed.

5. **Average Pizzas Per Order**  
   > How many pizzas are sold on average in a single order, calculated as:  
   `Total Pizzas Sold ÷ Total Orders`

---

## 🛠️ Tools Used

- **SQL** – for data extraction, cleaning, and calculating key metrics  
- **Excel** – for preliminary analysis and data verification  
- **Power BI** – for interactive dashboards and data visualization  

---

## 📊 Key Features of the Dashboard

- Clean, easy-to-understand charts highlighting sales patterns
- Dynamic filters to view sales by month, product, and order type
- KPIs displayed at the top for a quick business health check
- Visual insights that can help drive marketing and inventory decisions
